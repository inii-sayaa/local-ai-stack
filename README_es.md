## Overview

`local-ai-stack` es un conjunto de herramientas CLI y de orquestación de contenedores, diseñado para desarrolladores, que permite iniciar un entorno de IA privado y completo directamente en tu equipo local sin complicaciones.

Basado en **Docker Compose v2**, `local-ai-stack` proporciona modelos de lenguaje grandes (LLM) locales, una interfaz de chat, búsqueda vectorial, persistencia de bases de datos y una pasarela API compatible con OpenAI en cuestión de segundos. Los prompts, las conversaciones y los embeddings se procesan en tu equipo; la descarga inicial de imágenes de contenedores y pesos de modelos requiere conexión a Internet.
